Beautiful Gutenberg coupon block for SaveSleuth with a shared offers library in wp-admin.

== Description ==

Version 1.1.0 adds a shared offers library:
- Create coupon offers in wp-admin under SaveSleuth Coupons
- Reuse the same offer in multiple blocks by selecting the saved offer
- Reuse the same offer in shortcodes by ID or slug
- Change the code or affiliate link once and update all block instances

== Shortcodes ==

By ID:
[ss_coupon id="123"]

By slug:
[ss_coupon id="happy-420"]

Manual:
[ss_coupon store="Happy 420" discount="10%" code="SAVESLEUTH" url="https://happy-420.de/?ref=savesleuth" review_url="/de/stores/happy-420/" lang="de" variant="full"]
